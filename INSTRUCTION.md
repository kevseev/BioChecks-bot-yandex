# BioChecks Bot (Яндекс Мессенджер + LUNA)

## Что умеет

Бот принимает **фото** и **ссылки на картинки**, отправляет запросы в **LUNA Platform** и отвечает текстом и снимками с разметкой.

По кнопкам под сообщением:

- **1 к 1** — сравнение двух лиц, процент схожесть (matcher).
- **Атрибуты** — все лица на кадре: по каждому — фото с контуром и сводка (bbox, межглазное расстояние из **checkISO** / `eye_distance` при наличии, рот/глаза, эмоции, маска, поза головы, очки, перекрытия). Дамп полного ответа **POST /iso** и блок **дипфейк** в этой сводке не выводятся; оценку дипфейка см. отдельную кнопку **Дипфейк**.
- **Атрибуты тела** — все тела на кадре, атрибуты и контур.
- **Лайфнесс**, **Дипфейк**, **Качество изображения** — по основному лицу на снимке.
- **Детекция лиц** / **Тела** — отдельное фото с рамкой на каждый объект.
- **Детекция толпы** — число людей и точки на изображении.
- **Модификация изображения** — текстовая оценка признаков обработки кадра.
- **Сброс** — выйти из режима и очистить буфер для 1:1.

Без выбора режима: **два** изображения в одном сообщении (файлы и/или ссылки) — выполняется **1:1**. Команды **`/start`**, **`/menu`**, **`меню`** — показать меню; **`отмена`**, **`/cancel`**, **`сброс`** — как кнопка сброса.

## Установка

**Docker (рекомендуется)**

```bash
cp .env.example .env
# заполните .env (см. ниже)

docker compose up -d --build
docker compose logs -f bot
```

**Локально**

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.runner
```

## Конфигурация

Скопируйте `.env.example` → `.env` и задайте как минимум:

| Переменная | Зачем |
|------------|--------|
| `YANDEX_BOT_TOKEN` | OAuth-токен бота в Яндекс Мессенджере |
| `LUNA_BASE_URL` | URL LUNA, напр. `http://host.docker.internal:5000/6` из контейнера |
| `LUNA_HTTP_USER`, `LUNA_HTTP_PASSWORD` или `LUNA_BEARER_TOKEN` | Доступ к LUNA |

Опционально: `YANDEX_POLL_INTERVAL_SEC`, `YANDEX_UPDATES_LIMIT`, путь к файлу offset — см. `.env.example`.

**Парольный доступ (по желанию):** `BOT_AUTH_ENABLED=true`, путь к JSON с пользователями (`BOT_ACCESS_STORE` в Docker обычно указывает на смонтированный `access_auth/access_users.json`). Перед первым запуском: `mkdir -p access_auth && cp access_auth/access_users.example.json access_auth/access_users.json`. Для первого входа админов: `BOT_ADMIN_LOGINS`, `BOT_BOOTSTRAP_ADMIN_PASSWORD` (и при необходимости `BOT_BOOTSTRAP_ADMIN_LOGIN`) — при старте создаются записи для перечисленных логинов.

У бота не должен быть включён **webhook**, иначе `getUpdates` не отдаст события — отключите webhook в настройках Bot API.

## Как пользоваться

1. Откройте диалог с ботом в Яндекс Мессенджере.
2. Нажмите **`/start`** или **`меню`**, чтобы появились кнопки.
3. Выберите режим или пришлите **два** снимка/ссылки сразу для 1:1.
4. Отправьте **одно фото** из галереи и/или **ссылку** на картинку в тексте сообщения (можно несколько URL; для режимов с одним кадром обработается первое удачное изображение).

Если включена авторизация: первым сообщением введите **пароль одной строкой**, без вложений и без кнопок. Выход: `!logout` или `/logout`.

**Админы** (логины из `BOT_ADMIN_LOGINS`): `!users` — список; `!issue логин` — выдать новый пароль пользователю; `!revoke логин` — отозвать доступ.
